# 자연 대화 행동 전환: 첫 음성 기준 실험

실행일: 2026-10-29. **음성만 사용하는 WeSpeaker는 점수 대상 70개 발화를 모두 맞혔다. 이 시작용 표본에서는 화자 혼동을 재현하지 못했다.** 같은 사람의 전후 발화 쌍 12개도 모두 맞혔다. 현재 결과는 내용·맥락 편향이나 개선 효과를 입증하지 않는다.

## 무엇을 측정했는가

AMI의 원래 순서를 유지한 연속 대화 8개, 총 265.970초를 사용했다. 등록 음성은 40개이며 각 약 3초다. 2~4명의 알려진 화자와 발화 경계를 제공한다. 모델은 각 대화행동 음성만 임베딩하고, 별도 등록 음성 2개의 정규화 임베딩 평균과 코사인 유사도로 비교한다. 전사·정답·대화 행동·전환 라벨은 읽지 않는다. 일반 화자 분할/DER나 전사 성능 실험과 구분한다.

같은 사람 쌍은 전환 조건에서 ‘먼저 질문한 A → 나중에 답변한 A’, ‘먼저 답변한 B → 나중에 질문한 B’다. 대조 조건에서는 질문→질문, 답변→답변을 비교한다. **두 발화를 모두 정확한 실제 화자로 맞혀야 성공**이다. 계속 같은 오답 화자를 내는 경우를 성공으로 세지 않는다. 후보 쌍 16개 중 양쪽 모두 길이·겹침·잘림 조건을 만족하는 12개만 점수에 포함했다.

## 재현 자료

- `predictions.jsonl`: 실제 예측 화자·각 화자 코사인 점수·상위 점수 차이.
- `scores.json`: 전체 및 조건별 점수, 같은 사람 쌍의 상세 채점.
- `run_manifest.json`: 모델 커밋·SHA256, 입력 SHA256, 패키지·환경·실행 시간.
- `embeddings.npz`: 실제 발화·등록 임베딩.
- 실행 코드: `speaker_project/run_wespeaker.py`, 평가: `speaker_project/score_predictions.py`.
- 약 8.1초는 이 로컬 CPU에서 모델 세션 생성·추론·출력까지의 시간이다. 다운로드·패키지 설치는 제외했고, A5000 속도 측정값이 아니다.

공식 체크포인트: [WeSpeaker ResNet34-LM](https://huggingface.co/Wespeaker/wespeaker-voxceleb-resnet34-LM), 커밋 `f0c48c298fd835726c27956a5d617bad7115627e`. 원본 ONNX SHA256 `7bb2f06e9df17cdf1ef14ee8a15ab08ed28e8d0ef5054ee135741560df2ec068`. 전처리는 [공식 ONNX 예제](https://github.com/wenet-e2e/wespeaker/blob/master/wespeaker/bin/infer_onnx.py)의 80-bin Kaldi fbank, 25/10ms, Hamming, dither 0, 발화별 평균 제거 설정을 따른 별도 kaldi-native-fbank 구현이다. torchaudio와의 수치 일치 검사는 아직 하지 않았다.

## 결과의 의미와 다음 실험

이 결과는 **현재 깨끗한 등록 음성·정답 발화 경계가 주어진 소형 표본에서 음성 전용 방법이 충분했다**는 뜻이다. 자연 대화의 행동 전환이 항상 어렵다거나, 이 주제가 독창적이라고 증명한 결과는 아니다. 모든 8개 후보는 자동 선정 상태로, 청취 검토가 남아 있다. 작은 표본의 100%를 일반 성능으로 확대 해석하지 않는다. 평가 분할은 AMI 공식 test split과 다르다.

다음은 같은 등록 음성을 제공한 MOSS 통합 모델 비교다. 모델의 익명 ID를 등록 구간의 시각으로 연결하고, 실제 대화는 원래 순서를 유지한다. 통합 모델만 실패하더라도 등록 매핑·시각 누락·경계·발화 길이를 먼저 확인해야 한다. 모델 구조와 입력 단위가 다르므로 차이를 곧바로 내용 편향의 인과 효과로 해석하지 않는다.

현재 할 수 있는 기여 주장은 자연 대화의 행동 전환을 대상으로 한 **구체적인 평가 조건과 동일 인물 쌍 지표를 구현했다**는 수준이다. 어려운 사례·길이 대응 대조·개선을 확보하기 전에는 높은 독창성이나 새 알고리즘을 주장하지 않는다. 주제를 다시 바꾸기보다, 이 비교에서 실제 문제가 있는지 확인하는 것이 다음 판단 근거다.
