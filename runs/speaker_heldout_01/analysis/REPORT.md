# 미관측 4인 회의 8개 검증: MOSS 불안정성 재현, 고정한 보정이 불변성 회복

2026-10-29. 방법과 τ=0.10은 Starter set에서 고정한 그대로 썼다. 처음 보는 회의 8개에서 **한 번만** 평가했다.

**핵심 결과:**
- **MOSS 불안정성 재현:** MOSS는 8개 회의 중 5개에서 조건에 따라 화자 귀속이 바뀌었다. Main 70발화 중 23개(33%)가 흔들렸다. Starter의 2개 회의에서 본 현상이 미관측 데이터에서도 나타났다.
- **보정 결과:** 고정한 보정은 Main 불변 정답률을 67.1%에서 98.6%로 올렸고, 흔들린 발화를 0으로 만들었다.
- **WeSpeaker와 비교:** 보정은 WeSpeaker와 거의 같았다. Main 69 대 68, Hard 불변 정답 110 대 113이다.
- **Hard 트랙:** 어떤 방법도 불변 정답률 65%를 넘지 못했다.

## 검증 범위

- **결과 파일:** results_only.zip은 323,992B, 83파일이며 CRC가 정상이다. 계획된 80개 작업이 모두 완료됐다.
- **실행 환경:** shard 0/2는 GPU 4, shard 1/2는 GPU 5에서 돌았다(둘 다 RTX A5000). torch 2.4.0+cu118, Transformers 5.6.0, BF16이다.
- **일치 검사:**
  - 코드 5개 해시와 data/ami/heldout/inputs.jsonl 해시가 로컬과 같다.
  - 80개 입력(WAV 해시와 시각)을 로컬 원본으로 재구성했고 모두 일치했다.
  - 매핑과 투영도 80개 모두 재계산 결과와 일치했다.
- **자원:** 추론 합계 1,580초(GPU 2장 병렬), 최대 1.98GiB, 토큰 상한 도달 0회.
- **청취 검토:** 하지 않았다. 대화 구간은 주석으로 자동 선정했다.

## 해석

- **주장 가능:**
  - **불안정성은 일반적이다.** 통합 모델의 화자 귀속이 내용 보존 변형에 흔들리는 현상은 Starter 2개 회의에 한정되지 않는다. 미관측 4인 회의 8개 중 5개에서 재현됐다.
  - **보정은 미관측 데이터에서도 통한다.** 방법을 고정한 상태에서 정확도와 불변성을 함께 회복했다.
  - **불변 정답률이 차이를 드러낸다.** MOSS의 0초 단일 조건 정확도는 91.4%(64/70)로 높아 보인다. 그러나 불변 정답률은 67.1%다. 기존 정확도 지표만으로는 이 차이가 보이지 않는다.
- **주장 불가:**
  - **보정이 WeSpeaker보다 낫다:** 차이가 Main 1발화, Hard 불변 정답 −3발화다. 개선이라고 말할 수 없다. 짧은 깨끗한 발화(17개)에서만 보정이 앞섰다(100% 대 88.2%).
  - **화자 수가 원인이다:** held-out은 모두 4인이라 2·3인 대조군이 없다.
  - **질문↔답변 전환이 오류를 유발한다:** 전환 구간과 겹침 밀집 구간 모두에서 흔들림이 있었다.
- **결선 과제:**
  - Hard의 overlap_heavy와 short_overlap 계층은 모든 방법이 66% 이하, 41% 이하다.
  - 이 계층에서 불변성을 유지하면서 정확도를 올리는 것이 개선 목표다. 예: 겹침 음성 분리 후 임베딩, MOSS·임베딩 결합 규칙의 개발 세트 학습.
