# 질문하던 사람이 답변해도 같은 사람인가?

## 자연스러운 대화 행동 전환에서의 화자 귀속 안정성

상태: 사용자의 자연스러움 지적을 반영한 수정안. 대화 재배열은 본 평가가 아닌 보조 진단으로 낮춘다. 실제 대화 데이터에서 조건을 확보하고 오류를 확인하기 전까지 독창성·개선 효과를 확정하지 않는다. [수정 이유와 데이터 조건](NATURAL_CONVERSATION_REVIEW.md).

### 제출용 description

회의에서는 질문하던 사람이 답변하기도 하고, 설명을 듣던 사람이 상대의 설명을 요약하기도 한다. 본 챌린지는 **화자의 목소리는 유지되지만 질문·답변·설명과 같은 대화 행동이 바뀌는 구간에서 발언자를 올바르게 유지하는지** 평가한다. 같은 문장을 억지로 반복시키지 않고, 원래 순서가 보존된 연속 대화에서 이러한 전환 구간을 선정한다.

첫 트랙에서는 구간에 실제로 등장하는 2~4명 화자의 기준 음성과 발화 경계를 제공한다. 리더보드는 전체 정확도와 **같은 인물의 전환 전후 두 발화를 모두 정확히 맞힌 비율**을 함께 보고한다. 같은 오답 화자를 계속 배정하는 경우를 성공으로 세지 않는다. 발화 길이·겹침 등 음향적 난이도를 함께 기록해 짧아진 답변을 단순히 맥락 편향으로 오해하지 않도록 한다. 잡음 조건별 평가·후속 회복 지표는 확장 과제다.

음성만 사용하는 기준 방법과 음성·언어 통합 방법을 비교하고, 실패가 재현될 경우 음성 근거를 이용한 갱신 제어의 필요성을 검증한다. 이력 재배열은 모델의 민감도를 살피는 별도 보조 진단으로 둔다. 순서가 바뀐 인공 입력에서 오류가 생겼다는 이유만으로 자연 대화의 성능 문제를 입증했다고 주장하지 않는다.

### 한 문장 요약

**질문·답변의 주도권이 바뀌어도 실제 발언자를 유지하는지 자연스러운 대화에서 평가한다.**

### 첫 제출의 범위

- 기준 음성이 제공된 2~4명 화자의 발화 귀속. 다른 참여자의 발언을 제거하지 않으며 사전 정보 없는 일반 화자 분할과 구분한다.
- 발화 경계를 제공하고, 점수 대상은 단어 정렬 기준 타 화자 겹침 5% 이하로 한정한다. 엄밀한 무겹침 데이터는 아니다.
- 원래 발화 순서를 유지한 연속 대화를 우선한다. 공개 낭독의 재배열은 보조 진단에만 쓴다.
- AMI 공식 주석·음성을 이용한 시작용 연속 대화 8개와 등록 음성을 구성했다. CC BY 4.0 출처·라이선스를 포함했다. 전환 이벤트 청취 검토는 대기 중이다.
- WeSpeaker는 70/70 발화·12/12 동일 인물 쌍, MOSS는 68/70 발화·11/12쌍을 맞혔다. MOSS 두 오류는 지정 전환 전의 A 발화이며 후반 A 답변은 정답이다. 동일 인물의 ID 불일치는 관측했지만, 전환 후 악화·원인·개선은 입증하지 않았다. 자세한 분석은 runs/speaker_comparison/analysis/REPORT.md 참조.
- 같은 MOSS의 추가 2×2에서 동일 A 음성 두 개는 전체 대화 입력이면 두 등록 순서 모두 오답, 발화별 입력이면 모두 정답이었다. 다른 발화의 신규 오류와 등록 ID 미연결도 발생했다. 현재 근거는 입력 구조에 따른 민감성이며, 시간 위치·30초 청크·음향 문맥·언어 문맥을 분리한 인과 증명은 아니다. 상세: runs/speaker_moss_diagnostics_01/analysis/REPORT.md.
- 전환은 직업·신분 역할의 변경이 아니라 질문/답변 등의 대화 행동 변화다.

### 설명에서 드러내는 기여 후보

| 요소 | 구체적인 설계 |
|---|---|
| 데이터 | 원래 순서를 유지한 대화에서 질문·답변 주도권이 바뀌는 구간과 비교 구간 선정 |
| 성공 기준 | 누가 질문/답변하는지와 무관하게 실제 화자에게 발언을 올바르게 귀속 |
| 방법 | 관측된 실패를 기준으로 음성 근거의 활용과 외부 기준 갱신을 검증; 제어 방식은 아직 가설 |
| 검증 | 전체·전환 구간 오류, 발화 길이·음향 조건, 후속 오류, 정상 배정 훼손, 비용 공개 |

### 선행연구와의 관계

역할·언어 단서의 활용, 맥락 편향, 화자 오류 보정은 기존 연구에 있다. 여기서는 **실제 대화 행동이 바뀌는 구간에서 그 단서가 여전히 도움이 되는지**를 확인할 조건을 구체화한다. 자연 대화의 어려운 사례를 확보하거나 개선을 입증하지 못하면 독창성 높은 주제라고 확정하지 않는다.
